# 🚀 Featured Projects

## 🔥 Phoenix OS
### Self-Healing Real-Time Kernel for Embedded Systems

**ARM Cortex-M | QEMU | Custom RTOS | PendSV | Bootloader | GDB**

Phoenix OS is a final-year project focused on understanding and implementing the core concepts behind a real-time operating system for **ARM Cortex-M** systems.

### Working On

- Developing a custom **preemptive, priority-based RTOS kernel**
- Implementing ARM Cortex-M **context switching using PendSV**
- Designing task scheduling and synchronization mechanisms
- Implementing **semaphores and mutexes**
- Developing a **dual-bank bootloader with checksum validation**
- Exploring automatic firmware rollback and recovery
- Implementing lightweight inter-task communication
- Performing **GDB-based fault-injection and recovery testing**

> **Goal:** Explore how embedded systems can detect firmware-level failures and recover reliably without depending on an existing RTOS framework.

## ⚡ IoT-Based Three-Phase Power Failure Monitoring

**Arduino Uno | ESP32 | SIM800A GSM | ZMPT101B | ThingSpeak | Embedded C**

An IoT-based monitoring system designed to detect and report **three-phase power failures and voltage-related faults**.

### Key Features

- Real-time detection of **phase failure and undervoltage**
- ESP32-based Wi-Fi connectivity
- **SIM800A GSM** module for SMS alerts
- ThingSpeak dashboard for remote monitoring

- Watchdog-based recovery mechanism
